Because `VISTA-RL` currently contains no implemented code or experimental results, we recommend **unpinning it from your GitHub profile** (and optionally **archiving** or making it private until Milestone 1 has runnable, tested code).

- Faculty reviewers clicking pinned repositories expect runnable code, clear methodology, and verifiable results.
- An empty or placeholder pinned repo dilutes attention away from completed, tested repositories such as `BioTrace`, `PHARMAFORGE`, and `SYNAPSCODE`.

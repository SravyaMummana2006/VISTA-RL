# VISTA-RL

**Planned project: not yet implemented.**

## Scope

- **Goal:** Explore vision-guided reinforcement learning agents for sequential decision-making and visual control tasks.
- **Intended Approach:** Combine compact visual encoders (CNN or Vision Transformer backbones) with policy-gradient / actor-critic RL algorithms (e.g., PPO) evaluated on standard reproducible visual benchmarks.
- **Current Status:** Not started — no source code, environments, or experimental results exist in this repository yet.
